# ROBO 产品网站 / 本地三维原型

## 启动
在此文件夹打开终端，执行 `npm install`（首次），然后执行 `npm run dev`。
浏览器访问终端显示的本地地址。请通过 HTTP 预览，不要直接双击 index.html。

当前首页为 ROBO Hub（index.html）。选择 ROBO 1.0 进入产品结构探索页（robo-1.html）；旧 hub.html 地址跳转到首页。第一阶段仅展示官方作品，搜索与分类在浏览器完成，功能建议通过邮件发送。无业务后端依赖；目录维护见 HUB-NOTES.md，部署以 DEPLOYMENT-HANDOFF.md 为准。

## 已实现
- STEP 转换为 GLB，26 个独立实体，30,336 个三角形，1,141,680 字节。
- 围绕产品中心拖动旋转，支持完整水平环绕和顶部/底部查看；禁用平移以避免产品偏离画面。
- 滚轮平滑缩放，与右侧竖向滑杆、加减按钮同步（当前场景默认构图的 65%–220%）；触屏支持单指旋转和双指缩放。
- 通过拖动查看顶部和底部；重置视角保留爆炸程度和部件显隐状态。
- 用户缩放与爆炸图自动取景独立计算；接线教学按每一步的模型范围重新设定缩放基准。
- 爆炸程度滑块、动画展开和还原。
- 点击拾取或下拉选择部件，并高亮显示。
- 桌面和窄屏响应式布局、模型加载失败提示。

## PLA 材质与渲染管线
打印结构件使用 src/materials.js 中的 PLA Basic 外观近似材质；BOM 电子模块现已采用独立的 PCB、金属、塑料和镜头材质。
参考拓竹官方 PLA Basic 光滑表面描述：https://bambulab-us.myshopify.com/products/pla-basic-filament
官方颜色表：https://store.bblcdn.com/s7/default/716e7544652048698930b01d63307679/PLA_Basic_Hex_Code_Table_Refill.pdf
采用非金属物理材质：metalness 0、roughness 0.38、IOR 1.46，无透明、无清漆。
这些 PBR 数值为可调整的视觉近似，不是官方实测光学参数或官方 PBR 材质包。
保留用户指定配色：部件 26 为 #E87500，其余为 #FFFFFF。深橙色不是官方 Orange 色号。
未假设打印方向、层高或喷嘴规格，因此未伪造具体打印层纹。

src/rendering.js：PMREM 摄影棚环境光 + 三点布光 + PCF 阴影 → HDR 场景 → GTAO 缝隙遮蔽/去噪 → SMAA 抗锯齿 → Neutral 色调映射与 sRGB 输出。
精细画质限制 DPR 至 1.5；流畅画质关闭 GTAO、限制 DPR 至 1。两档均保留 PLA 材质、灯光、阴影与抗锯齿。
完全展开时自动扩大取景范围；地面高度随最低可见实体更新。

前面板使用基于 24 个实际灯珠位置的实时扩散近似（src/face-diffusion.js），包含距离衰减和表面朝向限制。隐藏点阵后同步熄灭，爆炸展开时随灯板位置更新。保留不透明白色塑料外观，未采用全板玻璃式透明。该效果不是体积散射或路径追踪，也未依据实际 PLA 壁厚、透过率及 LED 光通量校准。精细模式采用 VSM 阴影和最高 2 倍设备像素比。

## 公开留言板

留言板通过同源 `/api/messages` 接口读写，所有访问同一服务器的访客共享留言。默认数据文件为 `data/messages.json`（已加入 Git 忽略）；不要删除此文件。可用 `ROBO_DATA_DIR` 指向持久化数据目录。

- 本地开发：`npm run dev`，Vite 同时提供留言接口。
- 部署：先 `npm run build`，再 `npm start`。默认监听 `127.0.0.1:3000`，可配置 `HOST` 和 `PORT`，由反向代理提供 HTTPS。
- 单实例 Node 服务，数据目录必须位于持久磁盘并定期备份；不能只发布 `dist`，也不能让多个实例同时写同一 JSON 文件。
- 当前为匿名公开留言，支持昵称、分页、每个连接 IP 每分钟最多 5 条、内容长度校验及纯文本显示。尚无管理员审核/删除界面；反向代理部署时需在代理层配置访客限流（后端不信任转发 IP 标头）。
- 检查：`node scripts/validate-messages.mjs` 使用临时目录验证共享读取、并发保存、重启持久化和分页，不会写入真实留言。
