## 维护
- npm run models:bom：重新生成 public/models/components 下五种毫米单位 GLB。
- node scripts/validate-bom.mjs：验证 GLB 解析、几何索引、尺寸、材质批次和七处映射。
- src/bom-config.js：原 part ID → BOM 型号、方向、位置微调及显示说明。
- source-models/robocam.STEP 和 public/models/robocam.glb 未被覆盖，原装配仍可恢复。
- 每个 BOM 模块作为整组选择、展开，内部芯片和针脚不会在爆炸图中单独散开。
- 查看内部临时隐藏 18/25/26 外壳组；19 始终保持隐藏。

## SG90 实物照片修订
依据用户提供的两张照片更新三只舵机共用 GLB：半透明钴蓝薄壁外壳、两级齿轮罩、白色花键轴、开孔安装耳、壳体拼缝、黑金 Micro Servo / 9g / SG90 标签、棕红橙三芯短线及黑色插头。
原主体安装包络、轴位置和三个装配变换保留。含短线的总包络变为约 42.05×31.22×12.63 mm；这不是实际舵机本体尺寸或线长。照片没有尺寸基准，仍沿用原 CAD 的主体尺寸。
线缆路径及简化内部电机/齿轮轮廓仅为展示示意，未作为真实接线或制造依据。
照片本地副本：sg90-reference-1.png / sg90-reference-2.png。
字体来源：Three.js examples/fonts/helvetiker_regular.typeface.json；原字体授权信息保留在该 JSON 内。文字使用几何生成，不依赖远程纹理。
本地独立校对页：/qa/servo.html（开发工具，不纳入生产站点构建）。

## USB HUB 照片修订
部件 16 依据 hub-reference.png 更新：黑色圆角 PCB、四个并排下行 PH 接口及一个反向上行 PH 接口、接口空腔/触点/焊脚、五颗银色电容及顶面字样、右侧控制芯片/晶振/贴片元件、板面丝印与四个安装通孔。
保留 53×35 mm 板面、47.4×27 mm 孔距和原装配变换。元件高度按照片比例近似；展示包络 53×35×9.54 mm，不作为供应商标称高度。原规格表 36 mm 板宽与结构图 35 mm 的差异仍待实物确认。

## 摄像头照片修订
部件 15 按 camera-reference.png 细化：25×8 mm 黑色细长 PCB、阶梯式黑色镜头座和小型蓝色镜片、中部控制芯片与贴片元件、另一端米白色接口。展示总厚度 4.54 mm；元件布局及走线按照片近似，不是可制造 PCB 数据。原安装位置、朝向及爆炸分组保持不变。

## 点阵 LED 照片修订
部件 13 按正反面实物照片更新为两组 JY-MCU MAX7219 V2.0 外观：每组 8×8 乳白色圆角方形扩散窗、黑色前网格、白色背壳、窄绿色驱动板、上下带通孔的安装耳、背面芯片、焊点、两侧五针接口及丝印。灯珠保持未点亮状态。
照片未提供尺寸。继续使用原双模块约 64×32 mm 的正面安装尺寸作为基准；新增安装耳使总包络深度（局部 Z）约 37 mm。总展示包络 63.6×11.23×37 mm，耳孔、板厚及排针尺寸均为视觉近似，需实物核对。位置、朝向及整组爆炸动画保持不变。此次替换原先的圆形深色灯珠和整块大背板。

## LED 背面材质修正
不再使用整块实心灰白盒体，改为中空框架、0.38 mm 磨砂乳白透光背片、凸起边框、内部 LED 轮廓和少量模压凸点。透光参数为照片视觉近似，非材料实测数据。同步调整背面布局：JY-MCU 位于上方、V2.0 位于下方，控制芯片和排针随之对应。
总装配包络及之前前面板额外展开 35 mm 的设置不变。新增校验检查 GLB 保留磨砂透光物理材质。独立材质检查页 /qa/matrix.html 带后侧补光，仅用于观察表面细节。

## Nano Type-C 版本确认
用户提供 nano-typec-reference.png，替换之前的经典 Nano / Mini-B 参考外观：44×18 mm 黑色 PCB、圆角中空 Type-C 金属接口及中间舌片、CH340G、四边引脚主控芯片（ATmega328P-AU）、复位按钮、晶振、双排已焊针和尾部 2×3 ISP 排针。网页名称改为 Nano Type-C。
主板尺寸来自图片标注；芯片识别来自图片文字。元件位置、封装细节、排针高度和丝印为展示近似，不作接线或电气依据。模型总包络 18×14.8×44 mm（含排针）；保留部件 14 的原安装中心及爆炸分组。
